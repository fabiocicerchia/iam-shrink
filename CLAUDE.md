# CLAUDE.md

Guidance for Claude Code (and other AI agents) working in this repo.

## Project

`iam-shrink` is a Python CLI that turns CloudTrail usage data into minimized
IAM policies as Terraform diffs. Single module `iam_shrink.py` (entry point
`iam_shrink:main`, exposed as the `iam-shrink` console script). Tests live in
`tests/`. Requires Python 3.10+; depends on `boto3`.

## Commands

```sh
# build:  python -m build
# test:   pytest -q          (or: make test)
# lint:   ruff check .       (or: make lint)
# run:    iam-shrink analyze <role> --usage <events.json>
```

## Conventions

- Match existing style; don't reformat unrelated code. Formatter is `black`;
  lint is `ruff` (line-length 100).
- Conventional Commits for messages (see CONTRIBUTING.md) — they drive the
  release-please version bump.
- CHANGELOG.md is generated by release-please; don't edit it by hand.
- Never commit secrets; CI runs gitleaks. Keep `.env` out of git.

## Guardrails

- Don't add dependencies without a clear reason; prefer stdlib.
- Don't touch generated files or lockfiles by hand.
- Ask before large refactors or destructive operations.
